01 / The short version

Function Psi is an independent creative practice, not an agency. One person, a wide browser, and a network of collaborators.

South Africa / SAST / remote worldwide

I'm Rendani Manugeni, a creative developer from South Africa. I build digital things that move: 3D worlds, real-time instruments, and websites with a point of view. My work sits between design and engineering, which is exactly where the interesting problems live.

I started Function Psi to make room for work that does not fit neatly into a deck. The projects here are self-initiated concepts and studio-scale experiments. Some are tools, some are stories, all of them are built to be opened, touched, and judged in the browser.

The tagline is Making digital stuff is so cool. The positioning is One of the coolest websites out there. The first is a fact. The second is a standard I keep working toward.

02 / Principles

Four rules I keep breaking.

Not because they are wrong. Because the work gets better when a rule has a reason. These are the defaults I argue with.

01 / Principle

Make it feel first.

A page can be useful and still feel like a filing cabinet. I start with the feeling, then earn the utility.

02 / Principle

Motion is meaning.

Animation should explain something: hierarchy, cause, scale, or surprise. If it only decorates, it gets cut.

03 / Principle

Build the real thing.

I would rather ship a working interface than present a beautiful image of one. Real content, real devices, real constraints.

04 / Principle

Leave room to breathe.

The best moments need silence around them. Negative space is not empty; it is pacing.

03 / Toolkit

Tools are not the point.

The stack is whatever gets the idea into the browser without sanding off the interesting edges. These are the tools I reach for most.
