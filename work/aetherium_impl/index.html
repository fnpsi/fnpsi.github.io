Aetherium / Live Instrument

Aetherium

A spatial-audio instrument. Three frequencies. One chrome form that changes shape as you tune it.

Click to enable audio. Works best with headphones.

Tune the Instrument

Each slider controls a frequency band. The chrome form responds in real-time — geometry, light, and sound all linked.

Under the Hood

Web Audio Graph

  • Three sine oscillators (one per band) with individual gain nodes
  • ConvolverNode with generated impulse response for reverb
  • AnalyserNode for real-time waveform visualization
  • Master gain with smooth parameter automation

Three.js Scene

  • High-res torus knot (128 × 64 segments) with physical material
  • Custom vertex displacement driven by audio frequency data
  • Procedural room environment map for reflections
  • Orbital rings with instanced mesh, color-shifted per band
  • Shader-based particle field (2000 points) reacting to transients

Interaction Model

  • Sliders drive both audio params and visual uniforms simultaneously
  • Auto-evolve mode uses Perlin noise for organic parameter drift
  • Pointer parallax on desktop, gyroscope on mobile
  • Reduced-motion: disables auto-evolve, freezes particle animation
  • No WebGL: CSS chrome poster with static gradient rings
