A note on the work

The repos are real. The studies are honest.

The GitHub section is live data: names, descriptions, stars, forks, languages, topics, and update dates come straight from the API. The six case studies below are self-initiated concepts unless a page says otherwise. Any brands, products, or metrics inside them are fictional and used to make the design problem concrete.

If you want the short version, scan the index. If you want the reasoning, open a study. The code is static, the motion is intentional, and every page is built to be judged in a browser rather than a screenshot.
